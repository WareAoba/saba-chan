모듈형 게임 서버 관리 플랫폼

Palworld · Minecraft · Project Zomboid 등 여러 게임 서버를 하나의 데스크톱 GUI, 터미널 TUI, 디스코드 봇에서 통합 관리합니다. 모듈 시스템으로 새 게임을 코드 변경 없이 추가하고, 익스텐션으로 Docker 격리부터 음성 채널 음악 재생까지 자유롭게 확장하세요.

핵심 기능

하나의 데몬, 세 가지 인터페이스, 무한한 확장.

🎛️

이중 인터페이스 (GUI + CLI)

Electron 28 · React 18 기반 데스크톱과 Ratatui 기반 터미널 TUI가 동일한 Core Daemon에 연결됩니다. 상황에 맞게 선택하거나 동시에 사용할 수 있습니다.

🧩

모듈 시스템

Python 스크립트 + TOML 설정만으로 새 게임을 추가합니다. Core 재컴파일 없이 원격 매니페스트에서 커뮤니티 모듈을 바로 설치할 수 있습니다.

🧪

익스텐션 시스템

Docker 격리, SteamCMD 자동 설치, 음악 봇, UE4 INI 파서 등 게임 비종속 확장 기능. Hook으로 서버 라이프사이클에 자유롭게 개입합니다.

💬

Discord 봇 통합

사바쨩 prefix로 디스코드에서 서버를 직접 제어합니다. 한국어 별칭 시스템과 길드별 인스턴스 필터링을 지원합니다.

☁️

클라우드 릴레이 (server-chan)

NAT 뒤에서 포트 포워딩이 불가능해도 릴레이 서버로 Discord 제어가 가능합니다. argon2id + HMAC-SHA256 기반의 보안 프로토콜.

🎵

클라우드 뮤직 서버

음악 재생을 릴레이의 전용 music-server로 위임합니다. 쿠키 오프로드로 데이터센터 IP 차단 문제를 우회하며, Discord 내 UI 채널까지 지원합니다.

🛰️

자동 업데이트 시스템

GitHub Releases에서 Core · GUI · CLI · Updater · 봇 · 모듈 · 익스텐션을 개별 컴포넌트 단위로 배포. SHA256 해시로 무결성을 검증합니다.

🛡️

크래시 저항 설계

게임 서버는 항상 독립 프로세스로 실행됩니다. 데몬이 죽더라도 서버는 계속 돌아가며, 재시작 시 실행 중인 서버를 자동 재감지합니다.

🌏

10개 언어 i18n

한국어 · 영어 · 일본어 · 독일어 · 스페인어 · 프랑스어 · 포르투갈어(BR) · 러시아어 · 간체/번체 중국어를 내장.

빠른 시작

인스톨러로 5분 안에, 또는 소스에서 직접 빌드.

📦

1 · 인스톨러 사용 (권장)

GitHub Releases에서 Tauri 기반 독립형 인스톨러를 내려받고 실행합니다. Python / Node.js는 사바쨩이 포터블로 자동 부트스트랩합니다.

최신 릴리스로 이동
🛠️

2 · 소스에서 빌드

Windows에서 한 번의 PowerShell 스크립트로 Rust 워크스페이스 · Electron GUI를 병렬 빌드합니다.

git clone https://github.com/WareAoba/saba-chan.git
cd saba-chan
.\scripts\build-windows.ps1
🚀

3 · 서버 추가 & 실행

GUI에서 + 서버 추가 버튼으로 게임을 선택하고 설정을 입력하면 끝. CLI에서는 :instance create 를 입력하면 Step 위저드가 시작됩니다.

ℹ️ 자세한 사용법은 사용자 가이드에서

GUI / CLI 화면 구성, 모듈 · 익스텐션 관리, REST API 레퍼런스, 디스코드 봇 명령어, 설정 파일, 문제 해결까지 모든 내용을 공식 사용자 가이드에 담았습니다.
